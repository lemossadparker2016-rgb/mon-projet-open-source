# Codex-TestGen

An open-source Python library that automates the generation of unit tests for data pipelines and AI applications using OpenAI Codex.

**Note:** This project is currently in its early initialization phase as part of the OpenAI Codex for Open Source program.

## Objective

To bridge the gap between rapid AI development and software reliability by providing accessible, automated testing tools for developers globally.

## Installation

```bash
pip install -r requirements.txt
export OPENAI_API_KEY="your-api-key-here"

python -m codex_testgen.cli examples/sample_code.py
